# 04 优化prompt

## 优化前04：
我想要开发一个类似大众点评的网站应用，不需要太复杂的功能，只需要基本的功能就可以
## 优化后04：
开发一个简化版的大众点评网站应用，需要实现以下核心功能模块：

1. 用户系统：
    - 用户注册/登录功能（支持手机号+验证码或邮箱+密码方式）
    - 个人资料管理（头像、昵称、联系方式等基础信息）
    - 简单的用户权限管理

2. 商家模块：
    - 商家信息展示页面（名称、地址、联系方式、营业时间）
    - 商家分类浏览（餐饮、娱乐、购物等基础分类）
    - 基础搜索功能（按名称、分类、位置筛选）
3. 评价系统：
    - 用户评分功能（1-5星评价）
    - 文字评价和图片上传
    - 评价列表展示（按时间排序）

4. 基础技术实现要求：
    - 前端： 响应式设计，适配移动端和PC端
    - 后端： RESTful API接口设计
    - 数据库： 存储商家信息、用户数据和评价内容
    - 部署：支持基础云服务部署方案

5. 管理后台：
    - 商家信息审核与管理
    - 用户评价内容管理
    - 基础数据统计展示
   
系统应保证核心业务流程完整，包括商家展示-用户评价-内容审核-数据展示的完整闭环，同时保持
界面简洁、操作流畅。
